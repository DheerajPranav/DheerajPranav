### 🔭 What I'm building

- **[neurotusks-agent](https://github.com/DheerajPranav/neurotusks-agent)** — a CrewAI multi-agent system that researches, writes, and publishes NeuroTusks end to end, no manual editorial step.
- **Context-Aware LLM Memory Engine** — persistent long-term memory for conversational LLMs using vector embeddings and background knowledge-graph compression.
- **Autonomous PR Review Agent** — a CrewAI code reviewer wired into GitHub Actions that flags issues and leaves inline review comments automatically.
